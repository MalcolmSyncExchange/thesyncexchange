## Execution and authority

`runOne` claims only trusted jobs through an injected broker. It copies exact observed input into a private temporary directory, hashes streaming bytes, processes within a bounded child, and submits bounded evidence. It cannot accept assets, URLs, owners, destinations or executable flags from an Artist. No publication, acceptance, review, track-status or commerce operation exists in the worker.

`MediaBroker` is a separate deployment trust boundary. `PgAuthority` is broker-only; its pool uses a narrowly configured principal with only the foundation broker EXECUTE contract. It never belongs in the worker container. `LocalObjects` and the PostgreSQL fixture observer are disposable local adapters, not hosted Storage implementations. Worker requests carry only the exact lease tuple and an opaque, one-use output capability.

The additional migration `20261008231329_slice3_media_worker_fenced_io.sql` is **not installed**. It adds five nullable evidence columns to the private jobs table, a consistency constraint, `resolve_worker_io`, `record_worker_output`, and a jobs-only completion guard. No Storage DDL or provider ownership operation occurs. Functions fix an empty search path, are owned by postgres, revoke PUBLIC/anon/authenticated/service_role, and grant only the two broker RPCs to `submission_media_broker`. The trigger routine has no application EXECUTE grant. Existing table RLS/ACLs remain unchanged. All capabilities remain false on installation; all old jobs remain dormant until independently authorized.

Output fencing: capability binds exact job/asset/profile/destination/token/epoch, maximum bytes, and 30-second expiry. Broker stages bytes first, acquires the job row lock, validates live expiry immediately before create, observes immutable Storage identity/version, rechecks the lease, and records the output evidence. Completion independently validates the lease and matching output SHA/bytes. The database trigger rejects derivative success without exact recorded output evidence. Old leases cannot authorize writes or completion. Uncertain bytes remain private/unreferenced; no destructive rollback. Exact output replays can reuse verified identity without overwriting it; durable job evidence survives broker restart.

For a future hosted adapter, streamed staging must occur **before** the short locked commit. Timeout after Storage creation requires reconciliation of the exact immutable object and checksum. Reusable signed Storage write credentials must never reach the worker. The broker must authenticate an explicitly allowlisted workload identity before exposing this contract. The supplied image deliberately exits 78 (`MEDIA_BROKER_NOT_CONFIGURED`) by default: no hosted broker transport, Storage signer or credentials have been connected. The injected processing module and local adapters are executable; deployment wiring needs a separately reviewed source/configuration package before deployment authorization.

## Processing profiles

FFmpeg/ffprobe **9.0.2**, official source archive SHA-256 `8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e`. The exact source hash and build flags are in the Dockerfile/build script. Network protocols, automatic dependency detection, unrelated demuxers and tools are disabled. The build is LGPL 2.1-or-later, with native AAC and no nonfree/GPL codec libraries. Preserve license notices/source availability in any distribution. Release archive retrieval used official HTTPS and a retained SHA pin; independent release-signature verification is a release preflight item.

Master: WAV/AIFF/supported AIFF-C PCM/FLAC, decimal 250 MB, 1–900 seconds, mono/stereo, 8–192 kHz; approved PCM/FLAC depth policy. Bounded container walking rejects truncated chunks, oversized metadata and RIFF trailing polyglots. Full float decode counts frames, rejects nonfinite samples, checks container frame evidence, and derives duration. SHA-256 covers stored input bytes. Original bytes are unchanged. No gain, loudness, BPM/key or normalization work.

Waveform: 100 min/max envelope points/second across channels without summing/cancellation. 512-byte header (uint32 LE JSON length + bounded versioned JSON + padding), followed by interleaved signed int16 LE min/max. Header binds source asset/object/version/SHA and measured duration; no Master URL. Display-only clamp to [-1,1], never source normalization. <=90,000 points, <=2 MB. Deterministic fixed profile.

Preview: 100 ms region precision; 15–60 seconds, with whole measured cue for sources <15 seconds. Deterministic floor of ms*source-rate/1000, short cues use all frames. M4A/AAC-LC, 256 kbps target, 44.1 kHz, mono/stereo preserved, metadata/chapter/artwork/extra streams stripped, <=4 MB. Reopen/decode, validate codec/profile/channels, complete frame count, SHA and <=100 ms encoder padding tolerance. Provenance comes from immutable database source/region/sample/profile facts and worker build digest. Generation does not accept or publish output.

Artwork: full still JPEG/PNG/WebP decode; <=10 MB, 256–8192 each dimension, <=32 million pixels, ratio 1:4–4:1. Explicit APNG/WebP animation rejection; no transformation. Malformed inputs fail closed, metadata is not serialized or logged.

## Isolation and resource budget

Fixed argument arrays, no shell, filenames internally generated; protocol allowlist file/pipe. Parser receives no inherited credentials. Linux launcher applies no-core, 32-descriptor, 480-second CPU, 768 MiB address-space and output-file limits, plus architecture-checked seccomp network syscall denial. Landlock ABI >=3 restricts parser filesystem access to executable/shared libraries and the exact job scratch directory; unsupported kernels fail closed. Parent kills the entire subprocess group on timeout/abort or output bounds. Runtime 540 seconds per job, one job at a time, heartbeat every 30 seconds, SQL lease five minutes and max three attempts. Probe <=16 KiB; discarded stderr <=8 KiB. Per allocation limits and <=1 MiB source metadata. Temporary source <=250 MB, generated output <=4 MB. Container UID/GID 1000, read-only root, bounded /work tmpfs (uid/gid 1000, mode 0700), no network during local tests. Cloud Run/gVisor support for these syscalls must be proven before deployment; no permissive fallback is provided.

Node base is pinned by digest; Debian package installations are recorded in `/opt/runtime-packages.txt` but apt repositories are time-varying. Before a deployable image is approved, freeze a Debian snapshot/package lock, retain Linux amd64 build evidence and SBOM, verify release signatures, and scan the final image. These are explicit reproducibility/deployment limitations, not claims of bit-reproducible binaries today.

Synthetic test results and exact final security report are returned with the authoring report. Local tests cover decoder output, hostile files, lease takeover, row-lock contention, output replay, rejection of substitution, RLS/grants, and existing foundation/application behavior. Memory measurements include a 172,800,044-byte stereo 15-minute fixture; parent peak RSS and parser child peak RSS are reported separately. Memory-backed temp storage also counts toward a future Cloud Run allocation. No Cloud Run cost/resource change is authorized.
